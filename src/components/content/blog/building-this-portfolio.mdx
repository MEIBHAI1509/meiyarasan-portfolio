# Building My Developer Portfolio

I'm building this portfolio to showcase my work, technical skills, and journey as a developer.

## Why I decided to build it

A portfolio should be more than a collection of links.

I want this one to communicate how I approach problems, how I build products, and how I continue learning.

## The technology

The portfolio is being built with modern web technologies including:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js

## What's next

I'll continue improving the portfolio as I build more projects and learn new technologies.
